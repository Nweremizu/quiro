# 002 — Add `timing` and `anchor` to `Annotation`

**Severity:** MEDIUM · **Status:** TODO · **Blocks:** the eventual motion mode

## Problem

`Annotation` has no time dimension, so there is no way for a static composition
to become a motion one without converting every annotation into a different
type. Meanwhile the timeline already has `TextSegment` (`configuration.rs:909`)
and `MaskSegment` (`:865`) — the same user-facing concepts, timed, in a parallel
implementation the screenshot editor cannot reach.

This plan does **not** build motion mode. It adds the two fields that make motion
mode a UI change later instead of a data migration later. Landing it now, while
the annotation type is already being touched by 001, avoids a second migration.

## Change

Additive only. Zero behaviour change in static mode.

```rust
#[derive(Type, Serialize, Deserialize, Clone, Copy, Debug, PartialEq, Default)]
#[serde(rename_all = "camelCase")]
pub enum AnnotationAnimation {
    #[default]
    None,
    Fade,
    Typewriter,
    SlideLeft,
    SlideRight,
    SlideTop,
    SlideBottom,
    Scale,
}

#[derive(Type, Serialize, Deserialize, Clone, Copy, Debug, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct AnnotationTiming {
    pub start: f64,
    pub end: f64,
    #[serde(default)]
    pub track: u32,
    #[serde(default)]
    pub enter: AnnotationAnimation,
    #[serde(default)]
    pub exit: AnnotationAnimation,
    #[serde(default = "AnnotationTiming::default_transition")]
    pub enter_duration: f64,
    #[serde(default = "AnnotationTiming::default_transition")]
    pub exit_duration: f64,
}

/// Which space `x/y/width/height` are normalized against.
#[derive(Type, Serialize, Deserialize, Clone, Copy, Debug, PartialEq, Eq, Default)]
#[serde(rename_all = "camelCase")]
pub enum AnnotationAnchor {
    /// 0..1 of the capture. Rides zoom, pan, crop and padding.
    #[default]
    Capture,
    /// 0..1 of the output canvas. Immune to camera movement.
    Canvas,
}
```

On `Annotation`:

```rust
/// Absent = always visible (static semantics). Present = a timeline clip.
#[serde(default)]
pub timing: Option<AnnotationTiming>,

#[serde(default)]
pub anchor: AnnotationAnchor,
```

### The rule that has to hold everywhere

```
visible_at(t) = annotation.timing.map_or(true, |r| r.start <= t && t < r.end)
```

**Untimed means always visible.** Put this in one place — a
`impl Annotation { pub fn visible_at(&self, t: f64) -> bool }` — and have every
consumer call it, so no caller re-derives it and gets the `None` case backwards.
The `None` case is the one that matters: it is what lets a screenshot project be
opened in motion mode later without converting anything.

### Why `anchor` now

`Capture` is the default and reproduces today's behaviour exactly (annotations
are in frame coordinates, which move with the frame). `Canvas` exists because
callouts and titles want opposite things under a zoom: a callout arrow must track
the button it points at, a title card must not drift. Static mode never zooms, so
the field is inert today — but adding it later would mean re-migrating, and it
costs nothing now.

## Files

- `packages/crates/project/src/configuration.rs` — the three types, the two
  fields, `visible_at`, and a unit test that `timing: None` is visible at every
  `t` including negative and beyond-duration.
- `apps/desktop/src/utils/tauri.ts` is generated by specta — regenerate rather
  than hand-editing.

## Acceptance

- Every existing project file loads and serializes unchanged (the fields are
  `#[serde(default)]` and `None`/`Capture` round-trip to absent).
- `cargo test -p quiro-project` covers `visible_at` for: `None`; inside range;
  exactly at `start`; exactly at `end` (must be **false** — the range is
  half-open, matching how the existing segment types are consumed).
- No screenshot-editor UI changes. Nothing surfaces these fields yet.

## Risks

- **Specta generation.** `Option<T>` and `#[serde(default)]` interact awkwardly in
  the generated TypeScript — the file already carries a long comment about
  exactly this on `TimelineConfiguration.transitions`, where `skip_serializing_if`
  silently reset the optional flag. Check the generated `tauri.ts` types after
  regenerating rather than assuming.
- Resist adding an inspector for these fields in this plan. An animation picker
  with no renderer behind it is a UI that lies.
